# Yanns-Survey

SPUR Survey — Benji / Yans Deli conversational survey.

Single-respondent, chat-style adaptive survey. The AI reacts to each answer like a person would.

## Structure

- `backend/` — FastAPI app (main.py, requirements.txt)
- `frontend/` — Survey UI (index.html, survey.html)
- `Dockerfile` — Container definition

## Deploy

Deployed on nocbox-1 (10.220.3.168) at port 8030 via Docker Compose.
